## 🤖 LLM Code Generation Benchmarks
This repository serves as a sterile testing ground to evaluate different Agentic AI coding frameworks.
By maintaining a clean EF Core / Minimal API scaffold on the `main` branch, we can isolate and compare the code generation capabilities of various LLMs.

**Active Benchmark Branches:**
* `copilot-baseline`: Generation via standard GitHub Copilot.
* `reasonmcp-comparison`: Generation via [ReasonMCP](link-to-your-other-repo), a custom-built, local .NET 10 Model Context Protocol orchestrator utilizing Qwen-2.5-Coder.
